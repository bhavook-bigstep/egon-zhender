Custom recognizers

Added on top of Presidio's built-in recognizers and the config recognizers, on every detection request (requires a Presidio engine). Map each entity to a taxonomy category so it flags. A base score below the analyzer threshold means a match only counts when a context word is nearby. A checksum verifies each match: a pass becomes a deterministic finding, a failing match is dropped (kills false positives). Applied to new runs (the pipeline reloads); for a governed run, bake into the config.
